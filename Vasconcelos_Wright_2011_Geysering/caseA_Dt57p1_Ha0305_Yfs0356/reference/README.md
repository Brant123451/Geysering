# Reference

J. G. Vasconcelos and S. J. Wright, “Geysering Generated by Large Air
Pockets Released through Water-Filled Ventilation Shafts,” *Journal of
Hydraulic Engineering*, vol. 137, no. 5, pp. 543–555, 2011.

DOI: <https://doi.org/10.1061/(ASCE)HY.1943-7900.0000332>

The repository does not redistribute the paper. The compact CSV files in
`../data/` contain the Case A comparison traces digitized from:

- Figure 5: dimensionless pressure-head median and three-run envelope.
- Figure 7: dimensionless free-surface and air-water-interface levels.

Digitization precision is lower than that of the original measurements. The
CSV traces are comparison references, not raw experimental instrument data.
