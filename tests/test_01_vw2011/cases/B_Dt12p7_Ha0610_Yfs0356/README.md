### caseB 快照对求解器的 3 处物理修正（2026-07-06）

1. **塔基管顶基准（crown datum）**：通风塔物理上接在水平管**管顶**；旧耦合把
   管底（invert）压头 `Pj` 直接喂给塔基 ghost，多给了 ~ρgD（0.15 L）的虚假驱动，
   塔水位被推到 0.98 L 并被塔顶溢出钉死。修正后塔基感受管顶压力
   （满水结点 `Pj−ρgD`；气穴到结点后 `Pj−ρg·h_layer`），塔水位平衡在 ~0.84 L，
   与实验 Fig.8 的 0.80–0.85 一致。静力学核对：等温气囊 EOS + 实测塔水位 +
   管顶基准 与论文 Fig.6 平台自洽到 ~0.02 L。
2. **气囊驱动连通气核的鼻端进气（nose feed）**：气囊有超压且结点带气时，塔内
   从底部连通的气核是**一体被气囊供压的**——底部进气抬升气核**鼻端**（与水平管
   crown current 的 fill-to-body-level 闭合同构），而不是把气堆在底部单元让拖曳
   闭合把爬升限制在静水 Taylor 漂移（V*≈0.35）。鼻端填充水平取 Taylor 段塞单元
   的单元均值空隙率（0.5 × tower_core_area_fraction ≈ 0.41）。
3. **进气通量标定**：(a) 口径——气穴薄层贴管顶铺满 12.7 mm 塔口足印，进气口径按
   结点体空隙率 α/0.10 线性放开到全通（旧的按 α 缩口低估 ~10 倍）；(b) 上限——
   驱动吹通受逆流淹没（Wallis flooding，C=0.9 光滑管口）限制
   j_g ≤ C²√(gDr·Δρ/ρ)≈0.29 m/s，除以鼻端填充率得爬升 ~0.7 m/s，即论文 Table 2
   的 V*int≈1.4——**爬升速度是淹没限出来的，不是拟合出来的**。
