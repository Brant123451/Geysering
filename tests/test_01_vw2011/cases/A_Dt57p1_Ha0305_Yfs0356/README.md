# Case A — V&W(2011) 大塔工况（不喷发分支）

工况参数：`Dt = 57.1 mm`（Dt/D = 0.607）、`Ha0 = 0.305 m`、`WL_init = 0.356 m`。
对标论文数据：Fig.5（压头 H*，中排左列面板）与 Fig.7（Y*fs / Y*int，同面板），均为 Dt*=0.607。

## 文件夹自包含（代码冻结）

本文件夹是该工况的**独立快照**，不依赖仓库根目录的代码：

- `model/vw2011_network_twofluid.py` — 解耦两流体求解器的冻结副本（2026-07-02 版本）
- `model/digitize_paper_curves.py` — 论文图数字化工具的冻结副本
- `paper_scans/` — 本工况需要的论文原图扫描（Fig.5 = raw_p4，Fig.7 = raw_p6）

以后修改仓库根目录的模型代码**不会影响**本工况的结果；若要更新本工况，需显式覆盖 `model/` 里的副本。

## 复跑

```powershell
python caseA_digitize_and_compare.py
```

一条命令完成：数字化论文面板 → 冻结版模型复跑（t_end=9.0 s）→ 叠加对比图 → 指标 → report.html。

## 历史对齐状态（2026-07-05 记录）

模型侧本轮修复（已同步进 `model/` 冻结副本）：闭端假流量、幽灵空化并入气囊、
结点声学采样整流泵水（改为气囊 EOS 静压闭合）、阀门瞬开冲击（掺混墙+半隐式摩阻）、
突破排气判据放宽（体积中性 glug 交换下结点空隙率长期只有 5–15%，旧 20% 阈值
使排气支路成死代码）+ 排气闩锁（一次贯通后持续泄压，不被段塞间歇重新密封）。

- ✅ 分支正确：不喷发（模型水面最高 0.66L vs 实验 0.63L），界面追上水面、气体穿柱排出
- ✅ 压头平台：周期平均 0.52 vs 实验 0.54（T*≈1–7 全程贴带）
- ✅ 压头骤降（气囊排空）：模型 T*≈8.0 起跌、~9.2 归零 vs 实验 8.3 起跌、~9.3 归零

  t≈4s 内衰减）；实验迹线光滑。已核实为真实体积振荡（质量守恒、V-P 反相）而非数值伪振，

  0.2L；实验窗口内维持 ~0.6L）——方向一致、速率仍偏快，属气囊排空-补水路径的已知简化
