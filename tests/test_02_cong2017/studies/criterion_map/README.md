## 诚实结论（重要）

- 旧 README 的「7/7、62/63」出自**分级耦合**系统，其分类器与静态判据同构，
  属循环验证；旧产物保留在 `outputs/cong2017_*` 供对照。
- 全同步动力学模型抓对**分支端点**（16 mm 必喷 / 宽管必不喷 / Dr/D>0.62 全不喷），
  但对中等直径（21–31 mm）+ 大气量（L0 ≥ 1.2）组合**系统性低估喷发**。
- 机理定位（与 caseB README 已识别局限同源）：口部体积中性交换在水库供水布置下
  抵消进气抬水；关闭该交换救回顶托但废掉 B-H1 的气囊压力重建（已试已回退）。
  三个救援闭合变体（到达门控 / 蠕移下限 / 到达锁存 + 0.44√(gD) 前沿帽）均以
  B-H1 失喷为代价，全部回退，求解器保持与 caseA/caseB 哈希一致。
- 每构型 ~90–170 s 墙钟（i9 单核）；全套 7 + 63 约 2 小时（三分片并行 ~45 min）。
