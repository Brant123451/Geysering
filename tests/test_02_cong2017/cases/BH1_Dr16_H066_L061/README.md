### 对求解器的布置适配与快照闭合（2026-07-06）

**布置适配**（新增 NetworkCase 字段，默认值保持 VW2011 行为不变）：
1. `reservoir_head` — 上游定水头水库边界（满水 ghost + Dirichlet 压力 ghost，
   基准与模型满管压力场的塔水位 overlay 一致，静止态为精确离散平衡）；
2. `pocket_downstream` — 气囊在阀后下游段、初始常压（`air_head=0`）；
3. `x_riser_at` / `x_transducer_at` / `Hop_cap` — 三通位置、测点位置与驱动帽覆盖。

**快照闭合**（Cong 机理特有，均有物理动机、无逐工况拟合系数）：
4. H_op 阻力柱改用竖管**液体重量当量高度**（= Cong 论文式(2) 的 L_w 定义），
   而非可见水面高程；
5. 管顶前沿**越过三通继续推进 + 三通口补给**（论文 Fig.12b："只有部分气囊进入竖管"）；
6. 前沿**逆压头受阻**（局部环境管顶压力超过气囊压头时 Benjamin 前沿减速/停止，
   对应论文 Fig.13a t≈9.4 s 前沿停止；受阻后供给段压缩气囊 = 喷发驱动）；
7. 淹没限（Wallis）**同向流放宽**（水柱整体上升时 j_g ≤ j_flood + u_l）；
8. 表面排气加淹没限帽（防止驱动态气核被无限排空、喷发夭折）；
9. 基座 CCFL 限**方向感知 + 带气口封闭**（下泄一旦结点带气即按 CCFL 计——竖管水柱
   站在气体上，只能经环膜下泄；上喷用宽松防超采帽，实测水面速度峰值 ~2.8 m/s
   远超 3√(gDr)）；
10. 驱动态贯通判据收紧（带气表面≠气囊开放，防止咕嘟排气误判贯通提前泄压）；
11. **气囊全域供气**（连通气囊是等压一体，出口气量由整个气囊供给而非仅结点单元——
    单元供给在前沿受阻后 0.7 s 内枯竭，曾造成 4 s 的假僵持，预算探针定位）；
12. 驱动核**连续气柱填充水平**（Cong 16 mm 竖管为连贯气核+顶部水塞，Fig.8/9c；
    进气喂到水塞之下而非表面单元，堵死"进气即排气"的僵持回路）。
    （曾试 Wallis 耦合封锁下泄膜流——同时锁死了 Fig.9c 的 Lw 收缩路径，喷发更晚，
    已回退并在代码内注记。）

## 既有 1D 快照对齐状态（2026-07-08，非三维几何依据）

该 1D 快照曾以 Ta 运动学反推 `6.0/2.88 m` 有效长度，并以预算/僵持探针定位
三处闭合缺陷（第 9/11/12 条）。下表仅记录冻结 1D 结果；三维模型不继承这组反推
坐标，也不以分类结果校准参数：

| 指标 | 论文实验 | 模型 | 状态 |
|---|---|---|---|
| 是否喷发 | 是 | 是（水面到顶并持续溢出） | ✅ 分支正确 |
| 气囊到达竖管 Ta | 8.07 s | 7.56 s | ✅ 偏早 0.5 s（原 3 s） |
| 首脉冲水面上升速度 | 0.924 m/s（Table 2 全程平均） | 1.31 m/s（首脉冲段） | ✅ 同量级 |
| 首脉冲气核上升速度 | 1.231 m/s（同上） | 0.87 m/s（同段） | ✅ 同量级 |
| 喷发压缩激增 / H0 | ≈1.9（PT1，正文） | 1.71（t=9.16 s） | ✅ 量级锚点 |
| 喷发前压头形态 | 长平台 + 喷发前回落 | 同形态（回落 t≈9.9 vs 实验 ≈9.8） | ✅ |
| 水面到顶时刻 | 9.55 s | 11.58 s | ◐ 偏晚 ~2 s |
| 喷发形态 | 单次光滑加速爬升到顶 | 首脉冲至 ~1.25 m 回落，第二脉冲到顶 | ◐ |

- ✅ 机理链条与论文 Fig.12 一致：气囊沿管顶迁移 → 部分进入竖管 → 供给段受阻、
  气囊被压缩 → 压头激增 → 水柱整体喷出；首脉冲起爬时刻 ~8.7 s 与实验爬升段重叠，
  叠加图右板的平移斜率核对线显示首脉冲斜率落在实验散点内
- ◐ 喷发分多个脉冲、到顶偏晚 ~2 s：一维模型把喷发解析成"压缩-释放"极限环而非
  单调喷射——首脉冲把部分水柱抛出后气囊减压回落、再压缩再喷；实验的单次爬升中
  供给段动量（反射波）持续压缩气囊不给回落窗口，一维刚性回弹缺少三维破碎耗散
- ◐ 喷发后压力振荡 ±2H0 偏强：同源（刚性水柱回落再压缩）
- ◐ PT1 数字化平台 ~1.3H0 高于静水库头（传感器基准/标定存疑 ±0.3H0），压力对比以
  形态锚点（释放振荡、平台、喷发前回落、激增）为主；模型平台 0.95H0 与静水头一致
