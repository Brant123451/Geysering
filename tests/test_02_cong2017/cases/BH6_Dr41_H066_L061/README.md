# Case B — Cong, Chan & Lee (2017) Run B-H6（不喷发分支，高速摄像）

论文 Campaign 2 的不喷发分支代表工况。对应论文 `papers/cong2017.pdf`
（JHE 143(9):04017039）Series B 高速摄像组的 **Run B-H6**。
与 Case A（B-H1）**唯一的差别是竖管直径**——同一释放条件下分支翻转，
是"直径比主控喷发"结论最干净的受控对照。

## 当前对齐状态（2026-07-08，诚实记录）

| 指标 | 论文实验 | 模型 | 状态 |
|---|---|---|---|
| 是否喷发 | 否（气囊在竖管内破碎） | 否（水面最高 0.78 m，远未到顶） | ✅ 分支正确 |
| 气囊到达 Ta | 8.10 s | 9.16 s | ◐ 偏晚 ~1 s |
| 气核爬升速度 v_int | 0.476 m/s | 0.29 m/s | ◐ 泰勒尺度（0.22）偏向，实测有同向卷吸增强 |
| 气囊追上水面（破碎） | ≈10.5 s | ≈11.2 s | ✅ 接近 |
| 到达后管端压力 | ≈1.4 H0 缓峰 | 1.02 H0 缓峰 | ✅ 无激增形态正确 |
| 水面抬升幅度 | +0.63 m（0.58→1.21） | +0.19 m | ❌ 偏小（见下） |
| 水面上升速度 v_fs | 0.246 m/s | 0.02 m/s | ❌ 同源 |

- ✅ **与 Case A 的分支分化**（全耦合的关键核对项）：同一冻结求解器、只改 Dr——
  16 mm 喷发（压缩激增 1.71H0）、41 mm 不喷发（缓峰 1.02H0）。旧分级耦合给两工况
  相同的 2.07H0 峰压；全同步耦合恢复了"宽竖管排气抑制管道压力"的实验分化
  （实测 1.9 vs 1.4H0，模型 1.71 vs 1.02H0，方向一致、分化幅度偏大）
- ❌ **宽竖管水面顶托不足**：实验中泰勒气泡transit时水面被顶起 0.63 m（进气体积
  近一对一抬水柱，Fig.7a/c），模型的口部体积中性交换把位移抵消，只抬 0.19 m。
  尝试对水库背压布置关闭该交换：B-H6 恢复到 +0.6 m 量级，但 B-H1 的气囊压力
  失去重建路径、喷发消失——两工况在此闭合上的需求冲突说明口部交换需要按
  当地流态（泰勒气泡 vs 受驱气核）连续切换，超出本轮快照范围，已回退并在代码
  内注记（`tried and reverted, 2026-07-08`）。这与论文 Discussion 的
  "液膜卷吸/口部透射是一维闭合短板"结论一致，作为已识别局限如实写入论文
- ◐ 到达偏晚 ~1 s、气核爬升偏慢：宽竖管排气使气囊提前泄压，管顶前沿的逆压头
  受阻闭合略过度（与 B-H1 的 0.5 s 偏早同一闭合、相反方向）
