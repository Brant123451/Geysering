# Liu, Shao & Zhu (2020) 复现 — 论文 Campaign 3（原型背景交汇室竖井）

复现对象：Liu, L., Shao, W., & Zhu, D. Z. (2020). "Experimental Study on Stormwater
Geyser in Vertical Shaft above Junction Chamber." *J. Hydraul. Eng.*, 146(2), 04019055.
DOI: 10.1061/(ASCE)HY.1943-7900.0001660。原文 PDF：`../../references/liu2020.pdf`。

Edmonton 27 m 深竖井原型的 1:20 概化模型；本 Campaign 把论文的实验室基准
（VW2011、Cong2017）接续到带交汇室的现场尺度几何，并含解析振荡模型可三角验证。

选择逻辑：
- **A2 vs B3** 是论文原文点名的"只差下游条件"对照对——同一流量阶跃下分支翻转，
  与 VW2011 A/B、Cong2017 B-H1/B-H6 的分支判别叙事同构；
- **C9** 是论文自选的详细分析工况，且是三个 Series 里唯一有**封闭气囊释放**的
  ——与我们模型的截留气囊物理直接对应，同时挂上解析振荡模型（Eq. 7/8）做
  "实测 + 解析 + 数值"三方对照。

## 建模注意（相对 VW2011 / Cong2017 的新要素）

1. **进口边界是流量阶跃**（Q0→Q1，Tv≈0.4 s 斜坡），不是定压头释放——求解器进口
   BC 需支持 Q(t)；
2. **交汇室**（0.3×0.3×0.45 m 长方体 + 0.18 m invert drop）需要一维等效方案：
   局部容积节点或等效大直径短管段，取法记录在各 case README 并在论文里如实声明；
3. 竖管（dr=0.06 m）接交汇室顶盖中心，顶部敞开——竖井分支同 VW2011 的 θ=90° 处理。
