# Case B — Liu, Shao & Zhu (2020) Case B3（下游满管，单发喷发分支）

论文 Campaign 3 的喷发分支代表工况：Series B 的 **B3**。
与 Case A（A2）同一流量阶跃（20→100 L/s），仅下游初始条件不同（满管 vs 明渠），
试验结果翻转为 geyser——分支对照对的另一半。
论文对 B3 给出了最完整的过程记录（Fig. 5 流动照片 + 压力时程）。

## 当前状态（2026-07-08，首轮复现完成）

模型 = A2 冻结复合域求解器 + 两处声明扩展（结构性物理，非系数调参）：

1. **Series-B 工况开关**（`downstream_full=True`）：下游管初始满管、出口改为
   对固定尾水位 H_tail=Dd 的淹没出流面（带动量状态的出口结点面，与内部结点面
   同一闭合；尾门开度论文未报告，取与"初始满管"一致的最低尾水位，未拟合）。
2. **竖管刚性水柱 ODE**（带惯量）：(hr+L_eq)dwr/dt = g(H_lid−hr) − K·wr|wr|/2，
   与顶盖中心格双向交换体积；喷发速度与冲击峰正是本分支观测量，A2 的准静态列
   （0.25 s 滞后惯量替代）不够用。喷出高度 h_jet = Hr + wr²/2g（弹道）。

### 诚实声明（与 report.html 同步）

- **冲击峰是声学量**：随冻结数值波速 a=40 线性缩放（敏感性：a=80 → 63.5 kPa，
  接近实测 55，但负压过深、步长减半）。按冻结配置政策不改 a，如实报告 −44%。
- **高度—峰压物理关系正确**：模型 (PMax,h) 点几乎落在实验回归线上——误差集中在
  声学峰幅，不在喷发动力学。
- 事件时序偏晚 0.2 s（与 A2 涌波到达偏晚同源）；第二次柱涌起与实测
  "再振荡两周期"定性一致；振荡周期偏慢（论文自家解析模型 Eq.7 也偏慢一倍）。
- **已尝试并回退**：室内封闭气囊 EOS 加压方案（正反馈提前喷发，柱堵排气路）；
  出口瞬时孔口面（对刚性端格抖振）→ 改带动量出口面。

## 三维 OpenFOAM 验证

源算例位于 `openfoam/3d/`，论文输入审计见
`openfoam/3d/PAPER_AUDIT.md`。算例使用 OpenFOAM v2512
`compressibleInterIsoFoam`（可压缩两相热力学与几何 isoAdvector 界面输运）、真实圆管/
交汇室/竖管三维几何、下游满管淹没压力边界，以及
物理竖管口上方的外部大气域。后者允许水柱越过 1.22 m 竖管口，竖管口不是截断喷发的
压力边界。

不可压 `interFoam` 不用于 B3 压力峰验证：55 kPa 主峰和约 -20 kPa 回弹涉及水体与
气体可压缩性。水相采用 2.2 GPa 体积模量，气相采用理想气体；没有为匹配压力而降低
声速或增加封闭空气体积。尾门开度、接收水箱水位和 B3 初始室水位并未由论文给出，
其可复现边界实现及不确定性均在审计中单列。

复跑、网格加密和后处理命令见 `openfoam/3d/README.md`。三维后处理同时叠加论文
数字化曲线、现有一维模型和 OpenFOAM，并输出规定的压力、竖管、网格敏感性和守恒
指标。
