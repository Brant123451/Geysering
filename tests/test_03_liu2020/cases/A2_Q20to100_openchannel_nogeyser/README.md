## 终版（2026-07-08，复合域自然演化版）

按用户要求把整个过程改为**基于物理数学模型的自然计算演化**：抛弃集总节点+代数
交换面，上游管—交汇室—下游管为**同一条连续 PDE 复合域**（逐格断面几何），两处
断面突变为**带动量状态的内部结点面**（短连接管闭合，稳态自动满足能量平衡、瞬态
双向透射波动），竖管为室顶盖中心格的体积延伸（涌浪越顶注入 / Torricelli 回排）。

**当前可追溯证据边界。**现行入口先计算 10 s 的 Q0 暖机段，再记录 25 s；当前
`outputs/caseA_metrics.json` 可追溯到这一次 25 s 记录。旧说明中的 60 s 长程结果没有

未归档的历史观察，不能作为当前验证证据。现有归档给出：

## 复合域重构（2026-07-08，用户要求"整个过程基于物理数学模型自然演化"）

集总节点方案彻底废弃。现行求解器（model/liu2020_network_twofluid.py 的

un_case → _run_case_composite；旧实现保留为
un_case_lumped 供 A/B）：

- **上游管—交汇室—下游管 = 同一条连续 PDE 计算域**（逐格断面几何：圆管/矩形室），
  Rusanov 通量 + 锋面局域化的 minmod 压力梯度 + 满管弹性支路 + 封闭气囊区域 EOS
  （气相质量守恒，搁浅气归并；gas_vented 记账）；
- **两处断面突变 = 带动量状态的内部结点面**（短连接管闭合：dQf/dt = g·a·Δpiez/dx −
  (1+K)|u|Qf/2dx，半隐式）——稳态自动满足能量平衡，波动双向透射；瞬时孔口面会
  自整流抖振（逆 0.07 m 水头泵 100 L/s，已否决），纯施主面无水头约束（同样否决）；
- **竖管 = 室顶盖中心格的体积延伸**：任意室格涌浪越顶即注入竖管柱（物理：波峰触顶），
  回排仅经中心格、按 Torricelli 限速；喷发 = 柱高到管顶（溢出量记账）；
- PT3 读数含仪表闭合：正对进流射流的驻点动压份额（Cp=0.5，对报告稳态一次性标定，
  仅满管射流时激活）；PT2 = 竖管站立柱重（该柱作为"越顶注入 vs 回排"的动态平衡
  **自然涌现**，不是预设）。

ase A2（下游明渠，不喷发分支）

论文 Campaign 3 的不喷发分支代表工况：Series A 的 **A2**。
选它的理由：论文原文明确指出 Case B3 与 Case A2 **只差下游初始条件**
（"The initial conditions of Case B3 differed from that of Case A2 only in the
downstream condition"）——A2/B3 构成同一流量阶跃下"下游泄流能力决定是否喷发"
的最干净分支对照对，与 VW2011 Case A/B、Cong2017 B-H1/B-H6 的叙事完全同构。

## 历史开发记录（SUPERSEDED / INVALID_DO_NOT_CITE，2026-07-06）

以下内容只保留早期集总节点求解器的开发沿革；该实现及其输出已被现行复合域实现取代，
不得与本文件开头的当前可追溯 25 s 记录混合引用。用户当时指出两处伪影，同轮曾修复
若干求解器缺陷：

1. **0.5 s 涌浪**（管端贴交汇室的局部堆水）——初始条件非离散稳态 + 摩阻用了粗糙
   矩形水力半径（超摩阻使管道从进口倒灌壅水）。修复：圆管真实 Rh 查表、10 s Q0
   暖机段（t=0 重标到斜坡起点）。
2. **1.1 s 滞留气团凭空消失**——旧气相记账在格子充满时直接清零质量。修复：封闭
   气囊质量守恒（挤压搁浅的气体归并至最近气区、交给通风区时记账 `gas_vented`）。
3. 压力梯度改 minmod 限制器（中心差跨骑涨水锋，锋前格被一格压力墙猛加速，
   把锋前管段抽干——即涌波"停滞"在管中段的根源）；结点面侧压头取 4 格平均 +
   驱动头限幅（单格弹性尖峰拍打交换面）；满管端加孔口泄流支路；面速度上限 5 m/s
   （实测涌波 4.56 m/s）；出口损失按明渠通流/淹没收缩混合。
4. 调压井节点改纯体积守恒（盈余体积直接化为竖管柱 hr=E/Ar），记录柱高做
   0.25 s 一阶滞后（相机所见混合物锋面的惯量替代）。
5. 尝试并回退：出口面慢松弛（4×τ）、净交换制动（0.6 增益）——两者都把余荡
   反相放大到假喷发，代码中留有注释记录。
